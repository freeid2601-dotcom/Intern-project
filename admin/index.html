Static Deployment Workflow for GitHub & Hosting

Step-by-Step Guide

Because this site operates without a database or backend server, updates are deployed through clean, static Git version control. Follow these exact steps to publish content edits:

1
Generate HTML or Export JSON

In any management tab (Services, Products, Portfolio, or Blog), click the </> (Generate HTML) button next to any item. Copy the pre-formatted HTML card snippet.

2
Apply to Website HTML Files

Open the corresponding HTML file in your project:

  • Services: Paste into services.html inside <div class="grid md:grid-cols-2 lg:grid-cols-3 gap-6 mt-8">
  • Products: Paste into products.html inside <div class="grid md:grid-cols-3 gap-6 mt-8">
  • Portfolio: Paste into portfolio.html inside <div class="grid md:grid-cols-3 gap-6 mt-8">
  • Blog: Paste into blog.html inside <div class="grid md:grid-cols-2 gap-6 mt-8">
3
Commit & Push to GitHub

Run these exact terminal commands from your project root:

git add .
git commit -m "Update website content from admin panel"
git push origin main
4
Automatic Live Deployment

If using GitHub Pages, Vercel, or Cloudflare Pages, your live website will rebuild and deploy automatically within 30–60 seconds.

Why is this workflow used instead of automatic background publishing?

Operating without a backend server ensures 100% free hosting, zero database maintenance, maximum speed, and immunity to server-side attacks. Changes saved in localStorage remain in your browser until exported and committed to the static repository.
